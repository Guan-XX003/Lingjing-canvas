WanJuan Lingjing is an Electron desktop application whose renderer hosts a React Flow multimedia AI canvas. A trusted preload bridge connects the UI to main-process networking, files, project assets, local tools, updates, workspace services, and an account identity boundary that keeps refresh and enterprise workspace tokens in the main process. Fresh installs enter local mode without forcing account onboarding; the account surface opens only after an explicit user action. The boot splash remains visible until renderer/app-ready and presents a recoverable reload action on initialization timeout. The cloud prompt workspace keeps account-scoped templates, offline operations, and sync cursors in dedicated preload IndexedDB stores while the main process attaches account authorization to the prompt workspace API. A loopback-only automation service lets the packaged CLI and stdio MCP server invoke a deliberately limited task API with an ephemeral bearer token.
