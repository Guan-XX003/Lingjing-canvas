Local face detection and anonymization workflow for producing MP4 outputs. Windows x64 uses a packaged PyInstaller Deface runtime with the OpenCV CPU backend, requires no system Python or online install, and is a fail-closed packaging requirement. To avoid native codec failures for Chinese Windows usernames, Deface only reads and writes a per-task ASCII staging directory; Node copies the validated MP4 into the Unicode userData result directory and removes staging in success and failure paths. macOS keeps its existing bundled-venv resolution path.
