The application evolved from a bundled renderer and has been progressively decomposed into named React components, hooks, libraries, preload domains, and main-process services while preserving existing project data and provider behavior. Account identity is optional for local use; enterprise organization state is layered on top and must not mutate personal model configuration. Enterprise team prompt templates are stored by the local enterprise gateway, synchronized through the trusted preload/main-process boundary, and kept separate from personal and account-service cloud prompt workspaces.
